## Notas de operación
- adb shell UID 2000 NO puede matar al server (uid distinto): matar solo vía rish.
- El exit 255 de rish tras el kill no es fallo: es el transporte muriendo con el server.
- Si LADB se reinicia, el puerto 38639 puede cambiar: los scripts detectan el serial
  dinámicamente; nunca hardcodear el endpoint.
